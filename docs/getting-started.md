# 快速入门指南

本文档帮助您快速上手蜂巢智能体（Beehive Agent）。

---

## 前置要求

- **VPS 后端服务**：蜂巢智能体需要配合 VPS 后端服务使用，请确保您已有可用的后端服务器
- **账号**：需要有效的社交媒体账号（Twitter/X、Facebook 等）

---

## 安装客户端

请根据您的操作系统选择合适的安装方式：

- [Windows 安装指南](install-windows.md)
- [Linux 安装指南](install-linux.md)

---

## 首次配置

### 1. 启动客户端

安装完成后，启动 Beehive Browser 桌面端或访问 Web 前端地址。

### 2. 连接后端服务器

首次使用时，需要配置 VPS 服务器地址：

```
VPS 地址：http://YOUR_VPS_IP:8008
```

> ⚠️ 请将 `YOUR_VPS_IP` 替换为您实际的 VPS 服务器 IP 地址

### 3. 登录账号

配置好服务器后，使用您的管理员账号登录。

## 核心概念

### 租户（Tenant）

蜂巢智能体采用多租户架构，每个租户拥有独立的账号、环境和配置。

### 平台账号（Platform Account）

需要管理的社交媒体账号，如 Twitter 账号、Facebook 主页等。

### 代理 IP（Proxy IP）

用于社交媒体账号绑定的代理 IP，支持 HTTP/HTTPS/SOCKS5 协议。

### 自动化任务（Automation Task）

可配置的自动化运营任务，如自动发帖、自动回复评论等。

## 基本操作流程

### 添加社交媒体账号

1. 进入 **账号管理** 页面
2. 点击 **添加账号**
3. 选择平台（Twitter/X、Facebook 等）
4. 填写账号信息（用户名、密码）
5. 可选择绑定代理 IP
6. 点击保存

### 创建发布任务

1. 进入 **内容管理** 页面
2. 点击 **新建内容**
3. 编辑内容文本和媒体
4. 选择目标发布账号
5. 设置发布时间（可选）
6. 点击发布

### 查看运营数据

1. 进入 **数据看板** 页面
2. 查看今日发布统计
3. 查看账号健康状态
4. 查看互动数据

## 常见问题

### Q: 桌面端无法连接服务器？

**A:** 请检查：
1. VPS 服务器是否正常运行
2. 服务器地址和端口是否配置正确
3. 防火墙是否放行相应端口（默认 8008）

### Q: 账号登录失败？

**A:** 请检查：
1. 账号密码是否正确
2. 账号是否已被平台封禁
3. 代理 IP 是否可用

### Q: 自动化任务不执行？

**A:** 请检查：
1. 账号状态是否正常
2. 任务是否处于启用状态
3. VPS 后端服务是否正常运行
